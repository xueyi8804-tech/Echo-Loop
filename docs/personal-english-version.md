# 个人英语学习版说明

本版本复用 Echo Loop 的学习流程和录音功能。原有六篇材料保留，新增九篇、每篇五句：打招呼、听不懂时怎么说、数量价格、日常安排，以及询价、报价、样品付款、物流和售后。

## 中文翻译
六篇原有示例与九篇个人课程共85句，预置中文，不要求登录，不请求作者服务器、不消耗AI额度。它是随课程提供的译文，不是任意句子的实时机器翻译。导入其他材料、AI解析、意群、聊天等仍沿用原版的云端配置与限制。
App的母语设置应选中文；其他语言不会误显示中文译文。

## 课程语音
新增课程使用macOS Samantha英语合成语音，速度每分钟130词。构建时逐句生成音频，字幕时间取自实际音频长度，每句留0.6秒停顿。标题合集标明“合成语音”。它适合基础跟读，不代表真人自然对话。

## 后续自行修改
课程英文和中文只维护 lib/data/personal_courses.dart 一份。scripts/export_personal_courses.dart 将同一份英文传给语音生成脚本，字幕和语音自动同步；变更现有课程内容时需新增安装版本，并决定如何保留用户编辑，不要清除用户数据库。
GitHub个人编译流程会先生成音频、检查并测试，再编译iPhone包。Flutter固定3.41.5，Dart和iOS依赖沿用锁文件，没有升级依赖。
本地Mac开发先运行语音生成脚本，再运行App。Windows可以修改源码并通过云端Mac编译；不要直接以缺少个人课程音频的源码制作发布包。

## 更新到手机
下载最新构建结果的ZIP，解压后取IPA。它仍是未签名包，必须在家里的电脑上用Sideloadly给自己的iPhone签名安装。
使用昨天成功安装时相同的Apple账号、应用标识设置，尝试覆盖更新；保留旧App和学习数据，不要先卸载。Apple密码和验证码只在你自己的安装软件中输入。
“无法验证完整性”不能凭一张截图确认原因。新包会检查ZIP目录结构并提供SHA256校验值，但结构正确不等于苹果签名有效。如再失败，提供Sideloadly的错误日志或错误截图，再定位签名、证书、设备匹配等原因。
免费账号通常需每7天续签；Sideloadly自动刷新仍依赖电脑与手机能够连接，具体见 https://sideloadly.io/ 。

## 手机验收
1. 更新后能打开；现有课程与学习记录仍在。
2. 资源库找到“我的入门与电商英语 · 合成语音”，有九篇新课。
3. 不登录，打开原A1课程和新课程，点翻译能看到中文。
4. 切到下一句，中文与英文对应；退出重新打开仍正常。
5. 关闭网络后，内置音频、字幕和中文仍能使用。
6. 试一次跟读录音，允许麦克风权限，确认能录音、回放。
7. 新课程音频能播放、字幕与声音同步；读速是否适合由你实际体验反馈。

本轮不能替代iPhone签名安装和真机录音测试。保留成功或失败截图作为后续调整依据。
